# Use calibrated text as rolling correction context

Calibration processes Correction Units in chronological order and supplies previously Calibrated Text, when available, as the read-only context for later targets. Only corrections that passed the confidence gate and deterministic validation may influence later judgments; unchanged, rejected, or failed units contribute their Recognition Text. We accept the possibility of downstream influence from an earlier correction in exchange for stronger terminology and phrase consistency across adjacent sentences.
